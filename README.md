# 🧹 Cleaner v4.0

Безопасная утилита для очистки диска `C:\` на Windows 11 с графическим интерфейсом и диаграммами.

## ⚠️ Важно!
Программа выполняет реальные действия по очистке системы. 
- Запускайте её **от имени администратора**.
- Все удаляемые файлы перемещаются в папку `Cleaner_Backup` в вашем профиле (доступна функция отмены).
- Автор не несёт ответственности за возможную потерю данных. Используйте на свой страх и риск.

## ✨ Возможности
- Очистка временных файлов и кэша браузеров.
- Удаление старых точек восстановления и файлов гибернации.
- Безопасная очистка реестра.
- Встроенная проверка на вирусы (эвристика) и здоровье диска (SMART).
- Наглядные круговые диаграммы занятого места.
